# Personal Notes App - Frontend

## Technology Stack

- Next JS
- Redux RTK
- Tailwind css
- Shadcn ui Components 


## Features
- light mode /dark mode
- User (Register, Login)
- Notes are user-specific
- Responsive design
- Search/filter notes by title
- Lght/dark mode toggle
- Notes timestamps

## Setup Instructions

1. Clone this repository
2. Install dependencies:
   ```
   npm install
   ```

3. Start the project:
   ```
   npm run dev
   ```
